## 1. 本阶段目标与完成情况

按上一轮建议做三件事：

1. **CI**：查 `.github/workflows/` 发现 `ci.yml`（push/PR 跑 windows-latest 三绿）和 `release.yml`（打 tag 自动出 NSIS 发布）**早已存在且配置完整**，无需新增。
2. **真实站选择器基准**：新增 `scripts/selector-real-bench.ts`（`npm run bench:selectors`），抓两个长期稳定的爬虫沙盒站真实 HTML，用 linkedom 跑与生产同一段 inspect/scrape 脚本：
   - books.toscrape：自动推断 `li.col-xs-6...` 命中 20 项，抽出书名+价格（如 "A Light in the Attic / £51.77"）；
   - quotes.toscrape：`div.quote` 命中 10 项，抽出名言+作者。
   - **实测 2/2 通过**。
   - **真实发现**：books 的商品卡片外包一层网格 `<li>`，从内层 `.product_pod` 起算会因"同级无 ≥2 兄弟"而聚类失败——示例选择器需落到外层行节点。这是本地 fixture 测不出的真实结构问题，已记入 page-script 后续优化项。
3. **NSIS 本地打包实测**：`npm run build:sidecar`（裁 Python+OCR，370MB）+ `npm run dist` 全流程跑通，产物 `dist-installer/ruili-rpa-0.1.1-setup.exe`（**234.7 MB**）。electron-builder 自动对 exe 做了签名占位（signtool 自签，非正式证书）。
