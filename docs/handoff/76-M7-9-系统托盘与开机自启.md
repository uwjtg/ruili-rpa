## 1. 本阶段目标与完成情况

74/75 号诚实评估里"系统托盘图标 + 开机自启完全没做"。本切片补齐：

**系统托盘**：
- 新建 `src/main/tray.ts`，导出 `initTray / attachCloseToTray / markQuitting / destroyTray / isAutoLaunch / setAutoLaunch / shouldStartHidden`。
- 托盘图标复用 `build/icon.png`（已存在，537KB），16×16 缩放后挂上。
- 左键/双击托盘图标 = 显示并聚焦主窗口。
- 托盘右键菜单：显示主窗口 / 开机自启（checkbox）/ 检查更新 / 退出。
- **关闭主窗口默认收托盘**（`win.on('close')` 拦截 preventDefault + hide），从托盘"退出"才真退。

**开机自启**：
- 走 Electron 内置 `app.setLoginItemSettings({ openAtLogin, args: ['--hidden'] })`（Windows 即注册表 Run 键），零新依赖。
- 菜单 checkbox 状态实时从 `getLoginItemSettings()` 读。
- 开机自启带 `--hidden` 参数，主进程检测到后 `ready-to-show` 不再主动 show 窗口，静默进托盘。

**IPC**（供设置 UI 后续接入，本切片未改渲染端）：
- `autolaunch:get` → `{ enabled }`
- `autolaunch:set(on)` → `{ ok, enabled }`
