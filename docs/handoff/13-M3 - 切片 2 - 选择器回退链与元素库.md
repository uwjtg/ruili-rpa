## 1. 切片目标

按切片 1 交接文档 §6/§7 推荐优先级，把「拾取即点坐标」升级为**可复用的选择器 + 逐级降级定位**：

1. **选择器回退链**：`click_element` 定位策略从「UIA 弱匹配 → 坐标兜底」扩展为
   **严格属性 → 宽松属性 → ancestor 链 → index → 坐标兜底**，并上报命中策略；
2. **拾取时生成可复用选择器描述**：PickedElement 冗余记录
   windowTitle / processId / text / index / ancestor（旧流程已落盘 target 无这些字段时仍可回放）；
3. **元素库持久化**：picked 元素自动落 SQLite elements 表（签名去重），编辑器新增「元素」页签，
   支持列表展示 / 插入步骤（写为 pickElement 步骤的 target）/ 删除 / 刷新。

**不做的**（与切片 1 §7 一致）：智能录制 POC 顺延到切片 3；本轮不改 RunWireEvent 形状、不改
`pick:start/stop`、`registry:list`、`llm:`、`flow:` 既有 IPC 语义。

## 3. 关键设计决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| 回退链级数 | 严格属性 → 宽松属性 → ancestor → index → 坐标 | 与 Web 侧 `selector-fallback-design.md` 的理念对齐；每级都比前一级更容忍特征漂移 |
| 严格 vs 宽松语义 | strict=全部非空强特征；loose=任一非空特征 | 切片 1 的 `_find` 实际是「全部匹配」，并非注释所说「任一命中」——本轮显式区分并修正语义 |
| ancestor 存什么 | 只存祖先控件非空特征（controlType/name/automationId），近→远最多 3 层 | 结构锚点比目标特征更稳定；限制 3 层控制体积 |
| 特征全空怎么定位 | strict/loose 跳过 → ancestor 定位父容器后取父级第一个子节点 / index 按序号 | 对应真实场景：Electron 深层控件 name/automationId 常为空 |
| 元素去重键 | `windowHandle\|automationId\|name\|controlType`（UNIQUE） | 同一元素重复拾取不膨胀元素库；upsert 保持原 id |
| 自动入库位置 | 主进程 `pick:start` handler（不是 renderer） | 单一权威写入点；PickReply 附 `elementId?` 向后兼容 |
| 坐标兜底是否保留 | 保留，且窗口找不到也走坐标 | 与切片 1 决策一致（UIA 精确定位弱是既有遗留），但优先级已降到最低 |
| 旧 target 兼容 | 新字段全 optional，缺失即跳过对应策略 | 已落盘流程不破坏 |

## 5. 遗留与风险

1. **UIA 精确定位弱（既有）**：真实命中多靠 strict/coords；Electron 控件 accessibility 暴露不全
   （本轮冒烟中 UIA 找不到「拾取」按钮即为例证）。回退链已把 UIA 定位能力用到极致，后续可评估
   开启 `--force-renderer-accessibility` 或引入图像识别级。
2. **遮罩全透明**：除高亮框外不改变屏幕；「拾取模式是否开启」在 GUI 自动化里需用 `is_picking()`
   或日志判断（详见 §4.3），不是缺陷但容易误判。
3. **Tcl leaked 告警（既有）**：overlay 线程退出时仍可能触发
   `RuntimeWarning: the Tcl interpreter is leaked`（功能无损，gh-83274 已知行为）。
4. **ancestor/index 为空的比例**：任务栏「开始」这类根级控件 index=-1（父级 children 不含它），
   ancestor 兜底有效；深层表单控件才是 ancestor/index 的主战场，需更多真实应用样本验证。
5. **Git 基线缺失（2026-09 挂账）**：仍无 commit 基线，建议切片 3 前建立。
6. **元素库暂无「校验定位」功能**：插入步骤前无法预检元素是否仍可定位（click_element 会真实点击，
   有副作用）；如需要可加「只定位不点击」的 dry-run 端点。

1. **智能录制 POC**（切片 1 §7 顺延项）：复用 `_HookThread` 事件流（点击/输入/滚动）→ 指令序列，

3. **回放 dry-run 端点**：`/desktop/locate_element`（只定位不点击，返回 strategy + 命中控件 bbox），
   供元素库「校验」与运行前预检。
