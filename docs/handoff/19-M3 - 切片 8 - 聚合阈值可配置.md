## 1. 切片目标

关闭切片 7 §6 优先级 #1：**聚合阈值从写死常量提为可配置**。

此前录制聚合阈值是模块级常量，调参要改 Python 源码重启 sidecar：
`CLICK_DEBOUNCE_MS=350 / PX=10`、`TYPING_GAP_MS=800`、`SCROLL_GAP_MS=400`。
本切片把它们做成 **`/record/start` 可选 `thresholds` 透传**，缺省沿用默认常量；
非法/缺键/负数静默忽略，向后兼容旧客户端。

> 「校准」需要真人录真实操作对照调整，无法自动化；本切片交付**可调通道 + 安全默认**，
> 具体取值校准挂到后续真实使用时。

**不做的**（顺延切片 9）：录制流程参数化、坐标兜底点击前置窗口、圈定体验完善、设置面板 UI。

## 2. 完成项（代码落盘清单）

### 2.1 sidecar `desktop_pick.py`
- `DesktopRecorder.__init__` 新增 `self._thr` 字典，默认取自模块常量：
  `click_debounce_ms=350 / click_debounce_px=10 / typing_gap_ms=800 / scroll_gap_ms=400`。
- 新增 `_apply_thresholds(thresholds)`：只接受 dict，逐键 `int()` 化，**忽略 None / 非数字 / 负数 / 未知键**。
- `start(app_pid=0, target_pid=0, thresholds=None)`：录制前调用 `_apply_thresholds`。
- `_aggregate` 三处判定改读 `self._thr[...]`：
  - 点击防抖 `click_debounce_ms/px`；
  - 文本分段 `typing_gap_ms`；
  - 滚动聚合 `scroll_gap_ms`（位置用 `click_debounce_px`）。

### 2.2 sidecar `server.py`
- `/record/start` 解析可选 `thresholds`：非 dict → 400 `thresholds_invalid`；否则
  `_RECORDER.start(app_pid, target_pid, thresholds)`。
- 协议头注释更新为 `{"app_pid"?, "target_pid"?, "thresholds"?: object}`。

### 2.3 Node / 渲染链路（透传，无新 UI）
- `SidecarClient.recordStart(appPid?, targetPid?, thresholds?)`：驼峰转下划线发出
  （`clickDebounceMs→click_debounce_ms` 等）。
- `RecordController.start(targetPid?, thresholds?)`、主进程 `record:start` IPC、
  preload、`env.d.ts` 类型全部加可选 `thresholds` 形参。

### 2.4 测试
- `test_desktop_record.py`（+3，共 75）：
  - `_apply_thresholds` 覆盖默认、忽略 bogus/负数/非数字/None；
  - 把 `typing_gap_ms` 调到 50 → 0.1s 间隔也分段（验证阈值真的影响聚合）；
  - 默认 350ms 防抖下同位置 0.1s 两次点击合并为一条；
  - 修正 `_FakeRecorder.start` 签名为 `(app_pid, target_pid, thresholds)`（HTTP 路由测试连带覆盖）。

## 3. 关键设计决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| 配置通道 | `/record/start` body 一次性传入 | 录制前确定；不引入新持久化/设置存储，POC 最小闭环 |
| 取值时机 | start 时写入 self._thr，drain 时读取 | 一次录制用一组阈值；不支持录制中热改 |
| 非法值 | 静默忽略，沿用默认 | 调用方传错不崩录制；错误类型由 HTTP 层拦非 dict |
| 是否加 UI | 本切片不加 | 先打通协议与引擎；设置面板挂后续 |
| COORDS_CLICK_SIZE | 不纳入 | 是坐标兜底签名框边长，非聚合阈值 |

## 5. 遗留与风险

1. **未做真人校准**：默认值仍为经验值；真实使用后按效果微调。
2. **无设置面板 UI**：阈值目前只能通过协议/IPC 传；编辑器未暴露。
3. **不持久化**：每次录制都要传，不落 DB；下一轮可做设置存储。
4. **录制中不可热改**：改阈值需停录重录。
5. **录制流程参数化**、**坐标兜底前置窗口**、**圈定体验完善**仍挂账。

---

## 6. 下一步建议（优先级排序）

1. **录制流程参数化**：把录制出的字面文本/坐标暴露为可改变量（流程级参数）。
2. **阈值设置面板 + 持久化**：编辑器里调阈值并落盘，省去每次传参。
3. **坐标兜底运行层加固**：点击前 SetForegroundWindow 置前。
4. **圈定体验完善**：取消圈定、录制中显示当前圈定窗口、多进程目标。
