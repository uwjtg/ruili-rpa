## 1. 本阶段目标

承接 103/104 的回退链，再补三块：
1. **xpath 兜底**：录制/点选时额外生成元素到根的 XPath，作为回退链倒数第二个候选（比 CSS 路径更抗 class/顺序微调）。
2. **webInputSmart**：输入框也走回退链定位再 fill（此前只有点击有 smart 版）。
3. **webClickRelative**：行内相对位置锚点——给一个锚点选择器（如某行单元格），在其上行容器内点含指定文本的可点元素（"这一行的删除按钮"）。
