## 1. 本阶段目标与完成情况

M5-18 用的是 Electron 默认图标。本次：

- **设计图标**：紫底（#6B4EFF→#7C3AED 渐变）圆角方块 + 白色光标箭头叠加流线（呼应「桌面自动化 + 流程流」），2048×2048 PNG。
- **接入打包**：`package.json` → `build.win.icon = "build/icon.png"`，electron-builder 自动派生 Windows 多分辨率 .ico 并嵌入 exe / NSIS 安装程序 / 快捷方式。
- **开发态窗口图标**：`src/main/index.ts` `createWindow()` 在非打包态且 `build/icon.png` 存在时把它设为 BrowserWindow `icon`；打包态不设（Windows 任务栏/窗口图标自动取 exe 内嵌图标）。

未动 RunWireEvent / FlowDoc / sidecar 协议 / preload API。

## 2. 产出物

- `build/icon.png`（2048×2048，525 KB，源图）。
- `package.json`：`build.win.icon` 新增一行。
- `src/main/index.ts`：`createWindow()` 加 `devIcon` 计算并条件传入 `icon`；新增 `existsSync` 导入。

## 5. 遗留问题

1. **图标为占位稿**：当前是 AI 生成的通用风格图标，正式版可替换为品牌定稿（直接覆盖 `build/icon.png` 再 `npm run dist` 即可，无需改代码）。
2. **未做 macOS .icns / Linux .png 多尺寸导出**：V1 只发 Windows，无需处理。
3. **托盘图标未做**：当前无 Tray，等 M4 托盘静默运行器落地时再补 `tray/icon.png`（16/32 多尺寸）。
4. 图标在 PNG 源四角为白底（圆角方块外留白），Windows 安装/任务栏小尺寸下观感正常；如需纯透明底可后续重出图。

## 6. 对下一阶段的输入要求

- 换图标：只覆盖 `build/icon.png`（≥512×512，建议 1024×1024），重新 `npm run dist`。
- 托盘图标：待引入 Tray 时新增多尺寸 PNG（16/24/32/48），放 `build/tray/`。
