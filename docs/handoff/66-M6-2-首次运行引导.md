## 1. 本阶段目标与完成情况

**目标**：新用户第一次打开应用时不看到空首页一脸懵；给一个欢迎卡片说清楚三件事。LLM 厂商预设加硅基流动（免费模型多）。

完成：
- 新增 `src/renderer/src/components/WelcomeModal.tsx`：
  - localStorage `ruili-onboarded` 标记是否已看过；
  - 首次打开弹全屏遮罩 + 居中卡片；
  - 内容：欢迎标题 + 一句话说明 + 三个要点（模板起点 / 触发器 / AI 魔法指令需配 LLM）；
  - 「浏览模板」按钮跳 `/market`，「开始使用」关闭并写 localStorage；
  - 点遮罩也关闭。
- `src/renderer/src/components/AppShell.tsx`：挂载 `<WelcomeModal />`。
- `src/renderer/src/views/editor/LlmConfigPanel.tsx`：PRESETS 数组首位加「硅基流动（免费模型多）」→ baseURL `https://api.siliconflow.cn/v1`，model `Qwen/Qwen2.5-7B-Instruct`。

LLM 实测：用户提供桌面 api.txt（SiliconFlow key），已用 PowerShell curl 验证 `Qwen/Qwen2.5-7B-Instruct` 免费模型连通返回 "Pong!"。用户在 UI LLM 配置面板选「硅基流动」预设并粘贴 key 即可。

未做：多步向导（配 LLM → 建第一个流程 → 选触发器）；DB 持久化 onboarding 标记（用 localStorage 足够，重装即重看）；跳过/不再提示选项。

## 5. 遗留问题

1. **onboarding 标记在 localStorage**：用户清缓存或重装应用会再弹。自用可接受。
2. **未做多步向导**：当前只是单卡片。后续可加「配置 LLM → 建流程 → 选触发器」三步。
3. **LLM key 未持久化到 DB**：用户需在 UI LLM 配置面板选「硅基流动」预设并粘贴 api.txt 里的 key 保存。key 经 safeStorage(DPAPI) 加密。
4. **GitHub publish owner/repo 仍占位**。
