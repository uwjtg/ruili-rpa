## 1. 切片目标

关闭切片 6 §6 优先级 #1：**窗口移动后坐标兜底点偏**。

此前坐标兜底（UIA 回退链全部落空后的最后一级）直接使用拾取时记录的元素绝对包围盒中心点击；
若录制后目标窗口被拖动到新位置，UIA 选择器又因控件不可见（own-drawn / DirectUI）而失效，
点击就落在旧位置的屏幕空处。

本切片：
1. **拾取时记录顶层窗口矩形** `windowBoundingBox`（与元素 boundingBox 同源、同坐标系）；
2. **回放坐标兜底时**，若能重新定位到窗口 root，读其当前 BoundingRectangle，计算窗口平移量
   dx/dy，把记录的元素包围盒加上偏移后再点击；
3. 旧 target（无 windowBoundingBox）/ 当前窗口读不到 / 窗口未移动 → 原样返回，向后兼容。

**不做的**（顺延切片 8）：聚合阈值校准、录制流程参数化、圈定体验完善。

## 3. 关键设计决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| 怎么知道窗口移动了多少 | 记录时存顶层窗口 rect，回放读当前 root rect 求差 | UIA 看不到窗口内控件时仍能拿到窗口自身矩形；无需新交互 |
| 偏移作用范围 | 只加在元素绝对包围盒上（dx/dy），不改尺寸 | 窗口只平移不改大小；缩放/DPI 变化不处理 |
| 无记录窗口矩形 | 原样返回旧 box | 向后兼容旧录制产物（切片 1-6 落盘的 target） |
| 窗口 root 也没找到（最早期坐标分支） | 不做偏移，仍点旧 box | 连窗口都定位不到，无当前位置可参考 |
| 是否前置 SetForegroundWindow | 本切片不做 | 偏移修正是几何修正；前台置前/遮挡属运行层，挂账 |

## 5. 遗留与风险

1. **窗口缩放 / DPI 变化不处理**：只做平移修正；窗口拉大拉小后元素相对位置会变。
2. **多显示器 / 跨屏拖动**：平移量仍按矩形差计算，理论可用，但未在跨屏实测。
3. **坐标兜底未把窗口前置**：即便偏移算对，若有别的窗口遮挡该坐标仍点不到；挂账。
4. **聚合阈值未校准**（350/800/400ms）。
5. **录制流程参数化**、**圈定体验完善**（取消圈定、多进程）仍挂账。

   做成可配置（常量提为可调）。
2. **录制流程参数化**：把录制出的字面文本/坐标暴露为可改变量。
3. **坐标兜底运行层加固**：点击前把目标窗口 SetForegroundWindow 置前（避免遮挡点空）。
4. **圈定体验完善**：取消圈定按钮、录制中显示当前圈定窗口、多进程目标按顶层窗口树圈定。
