## 1. 本阶段目标与完成情况

改 Python sidecar 加坐标级鼠标 / 截图 / 前台窗口 4 个 endpoint，Node client 接线，暴露为 4 条指令。

**sidecar 新增 endpoint**（desktop_pick.py 加方法，server.py 加路由）：
- `POST /desktop/move_mouse` {x, y}
- `POST /desktop/click_coords` {x, y, button, double}
- `POST /desktop/screenshot` {path}（依赖 PIL.ImageGrab）
- `POST /desktop/foreground_window` → {hwnd, title, pid, rect}

**Node 新增 4 条指令**（desktop/commands.ts 扩 DesktopLike + 注册）：
- `desktopMoveMouse` / `desktopClickCoords` / `desktopScreenshot` / `desktopGetForeground`
