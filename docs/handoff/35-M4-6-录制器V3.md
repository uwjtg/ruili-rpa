## 1. 本阶段目标与完成情况

M4-5 录制器已覆盖点击/输入/滚动，但表单提交常靠按 Enter（不是点按钮），
不录 Enter 等于登录/搜索流程录不完整。本切片：

1. **录制功能键**：REC_START_FN 加 keydown 监听，只录导航/提交键
   （Enter/Tab/Escape/Arrow*/Backspace/Delete），字母数字不录（避免与 input 重复）；
2. **新指令 webPressKey(key)**：WebSession.pressKey → page.keyboard.press；
3. UI 事件转换加 `key → webPressKey` 分支。

**不做**：修饰键组合（Ctrl+C/Alt+Tab）；字母数字单键（已被 input 覆盖）；
字符级录制（V1 不做）。

## 5. 遗留问题

1. **真浏览器端到端未冒烟**：keydown 白名单/重注入/浮层均未在真实 Chrome/Edge 跑过。
2. 不录修饰键组合（Ctrl+C/Alt+Tab）——快捷键操作仍需手动加。
3. keydown 在 input 框里按 Enter 会同时触发 input（已录 fill）和 key（录 Enter）——
   可能重复：fill 已把值录了，Enter 作为提交键单独录一条，合理但用户需自己判断。
4. 不录 hover/右键/中键。

## 6. 对下一阶段的输入要求

- 录制器核心闭环已齐（click/fill/scroll/key）；下一步建议：
  1. **真站端到端冒烟**（用户手动）：开 Edge → 登录页 → 录网页 → 输账号密码 →
