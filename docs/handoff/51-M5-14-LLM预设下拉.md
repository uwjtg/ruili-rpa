## 1. 本阶段目标与完成情况

此前 LLM 配置要手填 baseURL 和 model，新用户不知道填什么。本次在 `LlmConfigPanel` 顶部加「快速选择厂商」下拉，选中后自动把 baseURL/model 填到当前激活的 Provider 卡片里（apiKey 仍需用户自己填，预设不带 key）。

预设：

| 厂商 | baseURL | model |
|---|---|---|
| 智谱 GLM | https://open.bigmodel.cn/api/paas/v4 | glm-4-flash |
| DeepSeek | https://api.deepseek.com/v1 | deepseek-chat |
| Kimi (Moonshot) | https://api.moonshot.cn/v1 | moonshot-v1-8k |
| 通义 Qwen | https://dashscope.aliyuncs.com/compatible-mode/v1 | qwen-plus |
| Ollama 本地 | http://127.0.0.1:11434/v1 | qwen2.5 |
