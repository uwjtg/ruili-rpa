## 1. 本阶段目标与完成情况

计划书 M4 的三类触发器（cron/interval/hotkey）补第三类：

1. **DB**：tasks 表加 `hotkey TEXT DEFAULT ''`（PRAGMA table_info 检测后 ALTER，兼容旧库）；triggerType 联合加 `'hotkey'`；createTask 校验 hotkey 非空；rowToTask 映射 hotkey；
2. **HotkeyManager**（`src/main/hotkeys.ts`，封装 electron globalShortcut）：reload(tasks) 先 unregisterAll 再为每个启用的 hotkey 任务 `globalShortcut.register(acc, cb)`；注册失败（被占用）只 warn 不抛；stop() 全注销；
3. **主进程接线**：HotkeyManager 与 TaskScheduler 共用 loadFlow/fire/markRan/isRunning 四个回调；whenReady、tasks toggle/delete 后同时 reload 调度器与热键；退出 hotkeys.stop()；
4. **TriggersView**：触发方式加「快捷键」选项，输入 Electron 加速器（默认 `Control+Shift+R`）；任务卡片 desc 显示 `快捷键: X`。

## 5. 遗留问题

1. **globalShortcut 真机未验**：HotkeyManager 依赖 Electron 主进程，vitest 跑不了；CRUD 与接线已验证，但真按键是否触发需开 app 手测（占键冲突时只 warn）；
2. **同一加速器冲突**：两个任务绑同一个键时后注册覆盖前一个（globalShortcut.register 对已注册键返回 false，当前只 warn）；后续可在 createTask 时查重；
3. **热键注册时机**：app 失焦/其他程序抢键时 globalShortcut 仍全局生效（这是预期）；
4. 文件监听触发器（目录新文件跑流程）未做；桌面+网页混合流程演示未做。
