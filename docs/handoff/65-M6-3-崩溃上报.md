## 1. 本阶段目标与完成情况

**目标**：自用模式下计划任务/机器人静默运行时，若程序崩溃需有迹可循。做本地文本崩溃日志（不接远程收集）。

完成：
- 新增 `src/main/crash.ts`：
  - `initCrashHandler()`：注册 `process.on('uncaughtException')` / `unhandledRejection`，追加写 `%APPDATA%\ruili-rpa\crash.log`；在 app ready 前调用；
  - `reportRendererError(message, stack)`：renderer 未捕获错误经 IPC 转发后落盘；
  - `reportRenderProcessGone({reason, exitCode})`：renderer 进程崩溃落盘。
- `src/main/index.ts`：
  - 文件顶部（import 后、app ready 前）调 `initCrashHandler()`；
  - createWindow 里 `win.webContents.on('render-process-gone', ...)`；
  - 新增 IPC `crash:report`（主进程接收 renderer 错误转发）。
- `src/preload/index.ts`：api 加 `crash.report(message, stack?)`（send 异步发，不阻塞）。
- `src/renderer/src/env.d.ts`：Window.ruili 加 `crash` 类型。
- `src/renderer/src/main.tsx`：挂载前注册 `window.addEventListener('error'/'unhandledrejection')` → `window.ruili.crash.report(...)`。

未做：crashReporter/minidump（需远程服务器，自用模式不上传）；崩溃日志轮转（当前无限追加，自用可接受）；RobotsView/设置页查看崩溃记录 UI。

## 5. 遗留问题

1. **crash.log 无轮转**：长期使用会无限增长。自用模式可接受；后续可加按大小/日期截断。
2. **未做崩溃 UI**：用户不知道有崩溃记录。后续可在设置页加「查看崩溃日志」按钮（打开 crash.log）。
3. **未接 electron crashReporter**：minidump 未启用（需远程服务器）。自用模式文本日志足够。
4. **文件损坏教训**：本切片开发中 PowerShell `Get-Content -Raw` 默认 GBK 读 UTF-8 无 BOM 文件导致中文乱码，破坏了 index.ts 的中文字符串和注释行。已从对话历史原文逐行修复。**后续改 .ts 源文件必须用 `[System.IO.File]::ReadAllText/WriteAllText` 显式指定 UTF8 编码，禁止用 Get-Content -Raw。**
