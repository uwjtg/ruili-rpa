## 1. 切片目标

关闭切片 12 §6 优先级 #1：**坐标兜底运行层加固——点击前 SetForegroundWindow 置前**。

坐标兜底（选择器链全部落空后按 boundingBox 中心点击）是 `_send_click` 的屏幕坐标点击；
目标窗口若被其它窗口遮挡，会点空或点到遮挡窗口。本切片在坐标兜底点击前把目标窗口
置前台（SetForegroundWindow），并处理 Windows 前台锁限制。

**不做的**（顺延）：变量弹窗增强（必填/说明/上次值记忆）、点击 boundingBox JSON 插值参数化。

## 2. 完成项（代码落盘清单）

### 2.1 `sidecar/desktop_pick.py`
- **Win32 声明**：`SetForegroundWindow / IsIconic / ShowWindow / AttachThreadInput`
  argtypes+restype 显式声明，`SW_RESTORE = 9`；
- **模块级 `_native_window_handle(ctrl)`**：取 UIA 控件自带窗口句柄，缺失/异常返回 0；
- **`locate_element`**：窗口根解析时记录 `root_handle`（句柄解析成功=原句柄；按标题重定位=
  根控件自身句柄；找不到=0），所有返回分支新增 `window_handle` 字段；
- **新方法 `_bring_foreground(hwnd)`**：最小化窗口先 `ShowWindow(SW_RESTORE)`；前台线程与
  当前线程不同时先 `AttachThreadInput(cur, fg, True)` 再 `SetForegroundWindow`，随后 detach；
  任何失败静默返回 False，不阻断点击本身；
- **`click_element`**：坐标兜底分支（`hit["control"] is None`）点击前，若有
  `window_handle` 先 `_bring_foreground` 再 `_click_box_center`。

### 2.2 `sidecar/tests/test_desktop_pick.py`（+5，共 80）
- 坐标兜底点击先置前（brought==[1]）再点中心；
- 窗口找不到（无句柄/无标题）→ 不调用置前，仍按坐标点击；
- 句柄失效→按标题重定位窗口根→置前用根窗口自身句柄（NativeWindowHandle=777）；
- `_bring_foreground(0/None)` 直接返回 False（不触碰 Win32）；
- `locate_element` coords 命中带 `window_handle`（有窗口=句柄，无窗口=0）。

### 2.3 冒烟脚本（.runtime，本地留存）
- `smoke_bring_foreground.py`：spawn 记事本 → `_bring_foreground(hwnd)` → 校验
  `GetForegroundWindow()==hwnd`，退出码 0 全绿。

## 3. 关键设计决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| 置前时机 | 仅坐标兜底分支（control 为 None）点击前 | 切片范围即「坐标兜底运行层」；UIA 控件路径有 Click 优先，行为不变 |
| 窗口句柄来源 | 解析成功的原句柄；失效则取重定位根控件自身句柄 | 句柄 404 时不能把失效句柄拿去置前 |
| 无窗口可置前 | 跳过置前，仍按坐标点击 | 兜底语义：能点就点，不因置前失败而放弃 |
| Windows 前台锁 | AttachThreadInput 附加前台线程后 SetForegroundWindow | 非前台进程直接 SetForegroundWindow 常被拒；实测（记事本）PASS |
| 失败语义 | 静默返回 False，不抛异常 | 置前是加固不是硬前提，失败不阻断点击 |

## 5. 遗留与风险

1. **控件路径（control 命中）未置前**：`_click` 的 UIA Click 失败回退 SendInput 坐标点击时
   同样有被遮挡风险；本切片只加固了坐标兜底路径，控件路径置前留作后续（改动面更大、涉及
   既有行为）。
2. **置前与点击无间隔**：SetForegroundWindow 后立即 SendInput；对响应慢的应用可考虑加
   短延时（当前未加，实测记事本正常）。
3. **多屏/DPI**：置前不涉及坐标换算，无新增风险。
4. **变量弹窗增强**、**点击 boundingBox JSON 插值参数化** 仍挂账。
