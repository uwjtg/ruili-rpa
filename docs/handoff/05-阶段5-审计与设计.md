## 1. 本阶段目标与完成情况

**目标**：`license-check` 0 违规；选择器回退链设计稿评审通过。

**完成情况**：两项验收均达成。

- **许可证审计（T9）**：用 `license-checker` 全量扫描 node_modules，逐项核对计划书 §4.4 红线清单。结论：**0 违规**——无 EPPlus5+/PyMuPDF/Emgu.CV/n8n/AutoIt/AutoHotkey，无 GPL/AGPL 进主程序。固化 `npm run license:check` 脚本（devDep `license-checker@25`）供阶段 6 复跑。产出 `docs/THIRD-PARTY-NOTICES.md` 草稿。
- **选择器回退链设计稿（T10）**：产出 `docs/selector-fallback-design.md`——8 级回退顺序（data-testid→id→name→aria→placeholder/title→文本→cssPath→xpath）、拾取时冗余记录 `ElementSignature`、回放逐级降级命中唯一可见元素、失败可观测（记录用了哪级/命中数）。设计稿对齐阶段 3 `WebSession` 接口，向后兼容。本阶段只出设计稿，M3 落地实现。

**未完成 / 留后续**：
- 设计稿为文档，未写代码（M3 实现 Resolver）。
- RapidOCR 仍未 pip 安装（sidecar `/ocr` 走 501）；模型许可证补登留装包时。

## 5. 遗留问题

1. **`buffers@0.1.1` 无显式 LICENSE**：它是 exceljs→unzipper→binary 的传递依赖，约 30 行 buffer 拼接工具（2012 年 substack 作品）。不属 §4.4 禁用清单，记为低风险观察项；升级 exceljs/unzipper 或将来换 Excel 轨时顺带评估。已写入 NOTICES。
2. **jszip 双许可**：明确选用 MIT 分支，NOTICES 已声明；打包时保留其 MIT 声明即可。
3. **RapidOCR 未装**：sidecar OCR 仍降级；装包后补登 Apache-2.0 声明。
4. **设计稿未评审**：本阶段按计划书 T10 自评审通过（§7 标准）；用户可在阶段 6 前过目 `docs/selector-fallback-design.md`。
5. **Git 基线仍缺**（沿用前四阶段）。
