## 1. 本阶段目标与完成情况

**目标**：让用户能把一条流程导出成 `.json` 文件带走，也能把别人给的 `.json` 流程包一键导入成自己的应用。

完成：
- **导出**：应用管理每张卡片新增「导出」→ 系统「另存为」对话框（默认文件名=流程名.json）→ 写出标准包。
- **导入**：应用管理头部新增「导入流程」→ 系统「打开」对话框选 `.json` → 读回并校验 → 另存为新流程（新 UUID，不动原文件）→ 列表刷新，绿条提示「已导入 xxx」。
- **包格式**（`src/shared/flow-package.ts`）：
  - 导出 = `{ meta:{app:'ruili-rpa-flow', format:1, exportedAt}, flow:{version,name,vars,steps} }`；
  - 导入兼容两种：标准包，或顶层就是 FlowDoc 的裸文件（向后兼容 / 用户手改）；
  - 纯函数 `parseFlowPackage(text)` 做 JSON.parse + 结构校验，错误给中文原因。
- 取消对话框不报错（「已取消」静默忽略）。

## 5. 遗留问题

1. 导出包不含运行日志/触发器配置，只含 FlowDoc 本体；导入后需在「触发器」里重新挂计划任务。
2. 导入的流程若用到未注册/缺失的指令，`parseFlowPackage` 只查结构不查指令注册——真跑时由 `validateFlow` 标 error（与新建流程一致）。
3. 大流程导出直接整体写文件，暂无进度条（单流程 JSON 通常很小，暂不需要）。
