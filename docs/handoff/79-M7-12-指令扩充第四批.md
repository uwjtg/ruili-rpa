## 1. 本阶段目标与完成情况

自实现 RFC 4180 子集 CSV 解析/生成器，不引入 papaparse 等新依赖。加 5 条：

- `csvParseText`：CSV 字符串 → 二维数组
- `csvReadFile`：读 CSV 文件 → 二维数组（自动剥 BOM）
- `csvRowsToObjects`：二维数组（首行表头）→ 对象数组
- `csvObjectsToRows`：对象数组 → 二维数组（含表头）
- `csvWriteFile`：二维数组写 CSV（默认加 UTF-8 BOM，Excel 双击不乱码）

新建 `src/engine/commands/csv.ts`，在 `buildEngineRegistry()` 注册；`engine/index.ts` 导出。

## 5. 遗留问题

1. **指令总数 79**，距 150 还差 ~71。未做：邮件 / 数据库 / Word / PPT / PDF / Excel 扩展。
2. CSV 解析器不支持换行符在引号字段内跨行（罕见但 RFC 允许）；当前按 LF/CRLF 分行。
3. 不支持自定义分隔符（只逗号）；无表头行推断开关（rowsToObjects 固定首行做表头）。
4. csvWriteFile 对单元格内换行不强制加引号（esc 函数会处理，但未测多行字段）。
