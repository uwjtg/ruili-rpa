## 1. 本阶段目标与完成情况

76 号 §7 建议下一批做零新依赖的剪贴板/弹窗。本切片基于 Electron 内置能力（clipboard / dialog / shell.beep）加 9 条指令：

**剪贴板（2）**：clipboardCopy / clipboardPaste
**对话框（5）**：showInfo / showError / showConfirm（bool 落变量）/ showOpenFile / showSaveFile

实现要点：
- 新建 `src/engine/commands/system.ts`，导出 `registerSystemCommands(reg, deps?)`；
- 把 Electron 能力抽象成 `SystemLike` 接口，默认实现**懒加载** `require('electron')`（不在顶层 import，避免 vitest node 环境崩）；
- 测试注入 stub，不真弹对话框；
- 已在 `buildEngineRegistry()` 注册；`engine/index.ts` 导出。

1. **指令总数 58**，距 150 还差 ~90。未做大类：邮件 / 数据库 / Word / PPT / PDF / CSV 更多字符串与日期处理 / Excel 扩展。
