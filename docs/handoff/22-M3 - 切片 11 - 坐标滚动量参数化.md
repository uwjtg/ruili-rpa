## 1. 切片目标

关闭切片 10 §6 优先级 #1：**坐标/滚动量参数化**。

切片 9 只把 `typeText` 文本抽成了变量；录制出的滚动指令里还有硬编码的滚动量与坐标兜底位置
（`scroll` 步骤的 `delta`/`x`/`y`）。本切片把这三个数值也抽成 number 流程变量：
- 录制时：`parameterizeRecording` 把 scroll 的 `delta/x/y` 替换为 `${scrollDeltaN}` 等引用；
- 回放时：scroll runner 对这三个字段先 `ctx.interpolate` 再转数字；
- 运行前：切片 10 的填值框自动列出这些 number 变量，用户可改。

## 2. 完成项（代码落盘清单）

### 2.1 `src/shared/record-params.ts`
- `nextVarName(used, base)` 改为按 base 前缀从 1 起扫描（修复跨 base 跳号 bug：原来从

- 新增 scroll 分支：遍历 `delta/scrollDelta`、`x/scrollX`、`y/scrollY`，数值字段抽为
  `{name, type:'number', value}` 并把 params 替换为 `${name}`；非数字/缺失不抽。

### 2.2 `src/engine/desktop/commands.ts`（scroll runner）
- `deltaRaw`/`xRaw`/`yRaw`：字符串形式先 `ctx.interpolate`，再 `Number()`；
  未定义变量插值为空 → x/y 回退 undefined（当前光标滚动），delta 回退默认 120。

### 2.3 测试（+3，共 112）
- `record-params.test.ts`（+2）：scroll delta/x/y 全抽成 number 变量并替换；缺 x/y 或非数字不抽；
- `commands.test.ts`（+1）：scroll 的 delta/x 为 `${var}` 时由 vars 解析为数字，未定义的 y 回退 undefined。

## 3. 关键设计决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| 参数化哪些字段 | scroll 的 delta/x/y | 这是录制中唯一硬编码的数值型可改量 |
| 变量命名 | scrollDelta1 / scrollX1 / scrollY1 | 前缀语义化，按 base 从 1 起扫描避让重名 |
| runner 如何处理 | 字符串先插值再 Number | 与 target/text 的既有插值模式一致 |
| 未定义变量 | 插值为空 → x/y undefined、delta 120 | 不报错，保持兜底行为 |
| 点击 boundingBox | 本切片不做 | 嵌套在 target JSON 里，参数化更复杂，挂账 |

## 5. 遗留与风险

1. **点击 boundingBox 未参数化**：它嵌在 target JSON 内，需 JSON 内插值，挂账。
2. **变量名无说明**：scrollX1 这种名对用户不够语义化。
3. **阈值设置面板 + 持久化**、**坐标兜底点击前置窗口**、**变量弹窗必填/记忆**仍挂账。
