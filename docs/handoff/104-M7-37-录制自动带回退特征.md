## 1. 本阶段目标

切片 103 让 webClickSmart 能吃特征 JSON，但录制出来的点击还是裸 `webClick(selector)`。本切片把回退链接进录制管线：录制一次点击，自动产出 `webClickSmart(featuresJson, cssPath)` 步骤，回放时按链自愈。

## 2. 产出物

| 文件 | 改动 |
|---|---|
| `src/shared/scrape/record-script.ts` | REC_START_FN 加 `featsOf(el)`；onDown 事件带 features；WebRecordEvent 加 features? |
| `src/preload/index.ts` | webRecord.stop 返回类型加 features |
| `src/renderer/src/env.d.ts` | 同上（渲染侧类型镜像） |
| `src/renderer/src/views/EditorView.tsx` | 录制点击事件若带 features → 生成 webClickSmart 步骤；否则照旧 webClick |

数据流：浏览器 onDown → `{type:'click', selector, features}` → IPC → EditorView 转步骤 → `webClickSmart(featuresJson=JSON.stringify(features), cssPath=selector)` → 回放 locateFirst 按 id→testid→aria→... 试。
