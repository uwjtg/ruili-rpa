## 1. 本切片目标与完成情况

**目标**：让设计器从"只能跑内置流程"变成"能增删改步骤、编辑参数、管理变量、看到运行时步骤高亮"——为后续切片（持久化、标签页、拖拽）打地基。

**完成情况**：
- **左侧指令库**（`CmdLibrary`）：从主进程 `registry:list` IPC 拉取全部 24 条指令元数据，按 group 分组、可搜索、点击即在选中步骤后插入新步骤。
- **中间步骤树**（`StepList`）：递归渲染树形 AST（`children` 嵌套 + 紫色引导线缩进 24px）；步骤行显示序号、分组首字图标、指令名、首参数摘要；选中态紫描边、运行态紫描边+外圈光晕、完成态序号变绿、禁用行半透明+划线、断点左缘红点。
- **右侧参数面板**（`ParamPanel`）：按选中步骤的指令 schema 渲染 text/number/select 表单，onChange 即时写回 `step.params`；含"删除此步骤"。
- **右侧变量面板**（`VarPanel`）：流程变量表（name/type/value），可增删改。
- **步骤操作**：悬停行显示 4 个按钮——断点切换、禁用切换、复制（深拷贝+新 id）、删除。
- **撤销/重做**：不可变快照（`commit()` 前 push past，上限 60），工具栏按钮按栈空禁用。
- **运行高亮**：`step-start` 设置 runningStepId，`step-end` 加入 doneIds；`run.start(flow)` 直接把当前编辑的 FlowDoc 发给主进程真实执行。
- **新增 IPC**：主进程 `registry:list` 返回 `Omit<CmdMeta,'summary'>[]`（runner/summary 函数被 IPC 自然丢弃）；preload `ruili.registry.list()`。

**未完成 / 留后续切片**：

- 多标签页（多流程并存、关闭、新建）——切片 2。

## 5. 遗留问题

1. **摘要简化**：步骤行副行只取第一个 text 参数的值，未用引擎侧 `summary()` 函数（函数无法过 IPC）。与原型/影刀的摘要体验有差距。建议切片 2 把 summary 逻辑用可序列化描述（如 `summaryTemplate` 字符串）从引擎下发。
2. **无拖拽**：当前只能点击指令库插入、不支持拖拽排序。§5 第 1/4 条的"拖拽"部分未做。
3. **无持久化**：刷新编辑器即丢失编辑。切片 2 接 SQLite。
4. **无多标签页**：单流程内存态。
5. **运行时选中态与运行态耦合**：当前 runningStepId 与 selectedId 独立，但完成态步骤不自动滚动到可见（M0 日志面板有自动滚动，步骤区未做）。
6. **步骤操作按钮 hover 显示**：用了 `opacity:0` 但无 CSS hover 规则依赖父元素——内联样式下 hover 可能不生效。建议切片 2 抽 CSS。
