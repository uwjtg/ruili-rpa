## 1. 本阶段目标与完成情况

此前 `llmClient` 在主进程模块加载时硬编码两个 Provider（cloud/local），apiKey 只读 `RUILI_LLM_API_KEY` 环境变量，用户在 UI 里根本没法配——AI 魔法指令对无环境变量的用户是摆设。本次把 LLM 配置完整接到设置页：

- **DB 持久化**（`src/main/store/db.ts`）：settings 表加 `llm.config` 键，存 JSON `{ active, providers: [{name, baseURL, model, apiKeyEnc}] }`；`loadLlmConfig()` 损坏/缺省回 null，active 指向不存在 provider 时回退第一个。
- **主进程**（`src/main/index.ts`）：
  - `llmClient` 由 const 改 let；whenReady 后 `reloadLlmClientFromDb()` 从 DB 重建，无 DB 配置则保持环境变量默认（无感升级）。
  - apiKey 用 `safeStorage`（Windows DPAPI）`encryptString`→base64 落盘，读时 `decryptString`；`isEncryptionAvailable()` 不可用时降级为明文兜底。
  - 新 IPC：`llm:get-config`（apiKey 不下发明文，只回 `hasApiKey:boolean`）、`llm:save-config`（apiKey 空串=保留旧值，非空=加密覆盖；保存后热重载 LlmClient）、`llm:test`（用激活 Provider 发一条 max_tokens=1 的 ping，15s AbortController 超时）。
- **UI**（`src/renderer/src/views/editor/LlmConfigPanel.tsx`）：新组件，挂在编辑器右侧「设置」页签 ThresholdPanel 下方。每个 Provider 一张卡：单选激活、baseURL/model 文本框、apiKey 密码框（占位显示「已设置/未设置」）；「保存配置」「测试连接」按钮。
- **preload/env.d.ts** 同步三个新方法签名。

未改 `FlowDoc` / `RunWireEvent` 形状；未加新 npm 依赖（safeStorage 是 Electron 内置）。

## 5. 遗留问题

1. 暂不支持 UI 增删 Provider（只有 cloud/local 两个可编辑）；要接新厂商只能改字段。后续可加「+ 新增」按钮。
2. `llm:save-config` 保存后立刻 `reloadLlmClientFromDb()`，无需重启；但 AiPanel 正在生成中的请求不受影响（用旧 client 跑完）。
3. 未做 Provider 预设下拉（智谱/DeepSeek/Kimi/Ollama 一键填 baseURL/model），用户手填；后续可加。
