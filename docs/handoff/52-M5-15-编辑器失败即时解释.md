## 1. 本阶段目标与完成情况

此前 AI 报错解释只能在 RobotsView 历史里点。本次在编辑器里跑失败后，日志区底部直接出紫色提示条，一键调 LLM 解释。

- **主进程**（`src/main/index.ts` broadcast）：flow-end 落库后、`runLog = null` 前，多 `send('run:end-meta', { runId, status })`——不污染 `run:event`（RunWireEvent 形状硬约束不能动）。
- **preload**（`src/preload/index.ts`）：`run.onEndMeta(cb)` 订阅，返回取消函数。
- **env.d.ts**：同步类型。
- **EditorView**：
  - state：`lastRunMeta` / `explaining` / `explainText` / `explainErr`；
  - `onEndMeta` 订阅记录；flow-start 时清空；
  - 日志面板下方紫色条：失败时显示「✦ AI 解释此错误」按钮，点击调 `ruili.llm.explainError(runId)`，成功展开解释文本，失败显示错误。

## 2. 产出物

- `src/main/index.ts`：broadcast flow-end 分支加 `run:end-meta` 推送。
- `src/preload/index.ts`：`run.onEndMeta`。
- `src/renderer/src/env.d.ts`：同步。
- `src/renderer/src/views/EditorView.tsx`：state + effect + 紫色解释条。
