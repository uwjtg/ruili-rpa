## 1. 本阶段目标与完成情况

74 号核对发现：指令库只有 ~33 条，距计划书 V1 目标 150-180 差很远。本切片挑一批**零新 npm 依赖**（只用 Node 内置 fs/promises + 全局 fetch）的高频指令先加上，共 16 条：

**文件（6）**：listFiles / readTextFile / writeTextFile（含追加模式）/ createFolder / copyFile / deleteFile
**网络（1）**：httpPost
**通知（3）**：notifyWebhook（通用 JSON）/ notifyDingTalk / notifyFeishu
**数据处理（6）**：listLength / listJoin / stringConcat / regexExtract（首个捕获组）/ jsonStringify / nowIso

实现要点：
- 新建 `src/engine/commands/util.ts`，导出 `registerUtilCommands(reg)`；
- 所有文件路径/文本参数走 `ctx.interpolate()` 支持 `${var}`；
- 通知类直接 POST JSON 到 webhook（钉钉/飞书格式按官方机器人协议）；
- 在 `runManager.buildEngineRegistry()` 注册；`engine/index.ts` 导出。
