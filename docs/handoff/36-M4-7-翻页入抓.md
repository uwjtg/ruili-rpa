## 1. 本阶段目标与完成情况

M4-1 webScrapeList 只抓当前页。真实列表站（电商/搜索）通常多页，
本切片加翻页循环：

1. webScrapeList 新参数 `nextSelector`（下一页按钮选择器，可选）+ `maxPages`（最多翻几页，含当前页，默认 1）；
2. runner 循环：抓当前页 → 若有 nextSelector 且未到 maxPages，点击下一页 → waitFor(listSelector) → 轻等 500ms 渲染 → 再抓；下一页不可点/未加载则停止；
3. 向导第三步加「下一页按钮选择器」+「最多翻几页」输入框；
4. generateScrapeFlow 透传两参数。

**不做**：自动检测"最后一页"（用户指定 maxPages）；URL 参数翻页（?page=2）；
懒加载滚动翻页。

## 5. 遗留问题

1. **真浏览器端到端未冒烟**：翻页循环/nextSelector 不可点容错均未在真实站验证。
2. 不自动检测最后一页——用户要自己估 maxPages；翻到末页 nextSelector 还在但点击无效果时会空抓一页。
3. 轻等 500ms 是硬编码，慢站可能不够；waitFor(listSelector, 5000) 能挡大部分。
4. URL 参数翻页（?page=N）不支持——只支持点按钮。
5. 翻页过程中若触发反爬/验证码，无处理。
