## 1. 本阶段目标与完成情况

计划书 M4 三类触发器补完（cron/interval/hotkey/file）：

1. **DB**：tasks 表加 `watch_path` 列（PRAGMA 检测后 ALTER）；triggerType 联合加 `'file'`；createTask 校验 watchPath 非空；
2. **FileWatchManager**（`src/main/filewatch.ts`，仅依赖 node:fs，不依赖 Electron）：
   - reload(tasks) 为每个启用的 file 任务 `fs.watch(watchPath)`；目录不存在则跳过；
   - 'rename' 事件 400ms 防抖（一次创建会触发多次），stat 确认是普通文件才触发；
   - 同文件 5s 内去重（防止写一半的临时文件反复触发）；
   - 跳过点开头文件；复用同一把 isRunning() 互斥锁；
3. **主进程**：whenReady、tasks toggle/delete 后同时 reload 调度器/热键/文件监听；退出 fileWatcher.stop()；
4. **TriggersView**：触发方式加「文件监听」选项，输入监听目录（placeholder 下载目录示例）；卡片 desc 显示 `监听目录: X`。

## 5. 遗留问题

1. **不递归**：fs.watch 非递归；子目录里的新文件不触发（recursive 选项 Windows 支持但跨平台不一致，MVP 单层）；
2. **不传文件路径给流程**：触发时只 fire flow，不把新文件路径写进变量；流程自身要知道处理哪个文件需自己扫目录（后续可加 `triggerFile` 变量注入）；
3. **文件还在写就触发**：防抖 400ms 后 stat 是文件就触发，大文件可能还在复制中；后续可等大小稳定再触发；
4. **目录被删/移动**：watcher 报错只 warn，不自动重建；
5. 桌面+网页混合流程演示未做。
