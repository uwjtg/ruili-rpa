## 1. 切片目标

关闭切片 9 §6 优先级 #1：**运行前变量填写对话框**。

切片 9 把录制出的 `typeText` 文本抽成了流程变量（`inputN`，默认值=录到的文本）。
本切片补全闭环：点「运行」时若 `flow.vars` 非空，弹出一个填值框，列出每个变量（名 + 类型 +
默认值预填），用户改完点「运行」才执行；「取消」则不跑。填值经纯函数合并进流程后交给解释器，
运行时 `ctx.interpolate` 自然替换。

无变量的流程行为不变（直接运行）。

## 2. 完成项（代码落盘清单）

### 2.1 新共享模块 `src/shared/run-overrides.ts`
- `applyRunOverrides(flow, overrides: Record<string,string>)` → 新 FlowDoc：
  - string 变量直接用填的字符串；
  - number 变量 `Number()` 转换，空/非法回退默认；
  - boolean 变量 `'true'/'1'` → true，其余 false；
  - 未填/未出现的变量沿用默认值；不修改原 flow。

### 2.2 渲染层 `EditorView.tsx`
- 新增 state `varDialog: Record<string,string> | null`（null=关闭）；
- `run()` 拆分出 `doRun(flow)`：流程有变量时用当前变量值预填 `varDialog` 并弹窗；否则直接跑；
- `confirmVarDialog()`：`applyRunOverrides` 合并 → 关框 → `doRun`；
- 新增固定浮层 JSX：遮罩点击关闭、变量逐项 input、「取消 / 运行」按钮，点遮罩或取消即放弃本次运行。

### 2.3 测试 `src/shared/run-overrides.test.ts`（+3，共 109）
- string/number/boolean 按类型覆盖；
- 未覆盖沿用默认且不改原 flow；
- 数字非法回退默认。

## 3. 关键设计决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| 弹窗时机 | 点「运行」且 vars 非空才弹 | 无变量流程零打扰 |
| 预填值 | 用 flow.vars 默认值 | 用户可在此基础上改，不必重录 |
| 类型 | string/number/boolean 转换，list/dict 按字符串 | 录制抽出的是 string；number/boolean 已有类型 |
| 取消语义 | 关框=不运行 | 避免误跑 |
| 在哪合并 | 渲染层纯函数 | 解释器零改动；纯函数可单测 |
| 是否阻塞其它操作 | 模态浮层 | 填值是运行前置，不希望后台改流程 |

## 5. 遗留与风险

1. **弹窗无校验/必填**：留空按类型规则回退默认，未提示必填。
2. **变量类型 UI**：list/dict 变量在弹窗里只是文本框，不结构化编辑。
3. **坐标/滚动量参数化**未做（切片 9 挂账）。
4. **阈值设置面板 + 持久化**、**坐标兜底点击前置窗口**、**圈定体验完善**仍挂账。

---

## 6. 下一步建议（优先级排序）

1. **坐标/滚动量参数化**：把坐标兜底位置与滚动 delta 也暴露为运行前可改参数。
2. **阈值设置面板 + 持久化**：编辑器调聚合阈值并落盘。
3. **变量弹窗增强**：必填标记、变量说明、上次值记忆。
4. **坐标兜底运行层加固**：点击前 SetForegroundWindow 置前。
