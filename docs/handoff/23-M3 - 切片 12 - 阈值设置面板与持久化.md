## 1. 切片目标

关闭切片 11 §6 优先级 #1：**阈值设置面板 + 持久化**。

切片 8 只把聚合阈值做成 `/record/start` 可选 `thresholds` 透传，编辑器无 UI、不落盘，
每次录制要么手工传参要么用写死默认。本切片补全闭环：

1. **共享纯函数** `src/shared/record-settings.ts`：默认值（与 sidecar 常量一致）、
   净化（与 sidecar `_apply_thresholds` 语义一致：只收有限非负整数，忽略非法/未知键）、合并；
2. **DB 持久化**：新增 `settings` 表（key/value），`saveRecordThresholds`（净化后与现存量
   合并落盘）/ `loadRecordThresholds`（缺省回退全量默认值）；
3. **主进程自动带上**：`RecordController.start` 以 DB 持久化阈值为 base、显式传值覆盖，
   起录制时总是发出完整阈值——用户改过设置后录制自动生效，免去每次传参；
4. **编辑器 UI**：右侧新增「设置」页签（`ThresholdPanel`），四项阈值可编辑、
   校验（≥0 整数）、保存、恢复默认，非法输入阻止保存并提示。

**不做的**（顺延）：坐标兜底点击前 SetForegroundWindow 置前（优先级 #2）、变量弹窗增强（#3）、
点击 boundingBox JSON 插值参数化（#4）。

## 2. 完成项（代码落盘清单）

## 3. 关键设计决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| 持久化载体 | DB `settings` 表（key/value，键 `record.thresholds`） | 切片 8 §7 待拍板「DB vs 文件」→ 选 DB：与应用/流程/元素同一存储，事务一致 |
| 默认值来源 | 共享常量与 sidecar 常量一致 | 单点事实源，防漂移 |
| 净化语义 | 与 sidecar `_apply_thresholds` 对齐（静默忽略非法） | 前端净化 + 后端净化双保险，行为一致 |
| 录制自动带上的实现位置 | 主进程 RecordController（base=DB，显式覆盖） | 渲染层零改动；「点录制即生效」；显式传参仍可用（向后兼容切片 8 协议） |
| 保存时校验 | UI 层阻止非法保存（非空/≥0 整数），主进程再净化 | 即时反馈 + 兜底 |
| UI 位置 | 右侧第 4 个页签「设置」 | 与变量/元素同区，无需新工具栏按钮 |
| 恢复默认 | 写回默认并立即保存 | 一键还原，无需二次点保存 |

## 5. 遗留与风险

1. **阈值无真人校准**：默认值仍为经验值；设置面板给了改的入口，具体取值待真实使用后调。
2. **无「录制中热改」**：改阈值需停录重录（sidecar 设计如此，未改）。
3. **坐标兜底点击前置窗口**（SetForegroundWindow）、**变量弹窗增强**（必填/说明/上次值记忆）、
   **点击 boundingBox JSON 插值参数化** 仍挂账（切片 11 §6 优先级 #2/#3/#4）。
4. **lint 既有告警**：`npm run lint` 存在基线问题（EditorView.tsx:134 setState-in-effect、
   env.d.ts:13 FlowSummary 未用、scripts/*.ts 等），本切片未新增 lint 错误，未纳入本轮修复。
