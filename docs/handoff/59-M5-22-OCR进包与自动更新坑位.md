## 5. 遗留问题

1. **安装包涨到 230.7 MB**（上版 151.3，+79MB，含 cv2/onnxruntime/rapidocr 模型）；桌面链路本身仍只需 uiautomation。
2. **build/python 370MB**：含 cv2(138MB)/onnxruntime(40MB)/numpy/PIL 等。若后续想瘦身，可考虑用 opencv-headless 替换 cv2 或裁剪 RapidOCR 模型。
3. **pip install 需联网**：干净机上首次 build:sidecar 要能访问 PyPI；内网需配 `pip` 镜像。
4. 自动更新坑位是空实现，正式发版前仍需接 electron-updater + 更新源。
5. OCR 真实识别准确率未做端到端图测（需一张中文截图走 /ocr），仅验证引擎加载成功。
