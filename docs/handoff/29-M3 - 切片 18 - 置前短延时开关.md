## 1. 切片目标

关闭 NEXT-PROMPT 最后一个 M3 可选小项：**置前后短延时开关**。切片 13/16 在所有点击
路径（控件 + 坐标兜底）前统一 `_bring_foreground(hwnd)`；当时实测记事本无需延时、未加。
本切片把「置前台后等待 N ms」做成全局可配置开关，**默认 0（关闭）**，给个别需要
等待窗口动画/焦点稳定的目标应用留一个调节口。

**不做**：per-flow 覆盖（全局开关即可，M3 范围最小化）。

## 3. 关键设计决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| 默认值 | 0（关闭） | 切片 13/16 实测记事本无需延时；不改变既有行为 |
| 配置范围 | 全局，不做 per-flow | 收尾小项；per-flow 是 M4 话题 |
| 生效时机 | 保存即推（sidecar 已在跑）/ 下次启动推 | 无需重启应用；推送失败静默 |
| 上限 | 10000 ms | 防误填拖死回放；与 sidecar setter 同口径 |
| 失败语义 | 置前/推送失败均静默不阻断点击 | 沿用切片 13/16「加固非硬前提」 |

## 5. 遗留与风险

1. 延时在每次点击前都 sleep（含 retry 循环每次成功定位）；默认 0 无开销，调大后回放变慢——预期行为。
2. 未做真实目标应用端到端验证（仅单测覆盖 sleep 调用与端点路由）。
3. AlwaysOnTop 窗口被置前无效的老问题仍挂账（切片 16 遗留）。
