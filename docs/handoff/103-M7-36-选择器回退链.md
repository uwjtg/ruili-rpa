## 1. 本阶段目标与完成情况

此前点选拾取只存一条 CSS 路径，页面一改版（class 加 hash、顺序变动）就失效。本切片落地计划书 §6.2 的回退链：

- **纯函数** `src/shared/scrape/fallback.ts`：`buildFallbackSelectors(features)` 把录制时冗余抓到的特征按稳定性排序成候选数组——
  `#id → [data-testid] → [aria-label] → [name] → [placeholder] → [role] → tag.stableClass → text= → 全 CSS 路径`，自动去重/跳过空值/转义属性值/超长文本不进 text 候选。
- **录制端** `pick-script.ts`：PICK_START_FN 现在除 selector/tag/text 外，同时抓 `features`（id/name/aria-label/data-testid/role/placeholder/classStem）冗余存下；`PagePickResult` 类型加 `features?`。
- **回放端** `WebSession.locateFirst(candidates)`：RealWebSession 按候选顺序逐个 `locator.waitFor({timeout:1500,state:'attached'})`，返回第一个命中的选择器；全不命中返回 null。
- **新指令** `webClickSmart`：吃「特征 JSON + 兜底 cssPath」，构造候选链 → locateFirst → 点击实际命中项，并日志打印试了几个候选。
