## 1. 本阶段目标与完成情况

补计划书 §4.1 点名、但此前完全缺失的数据库能力域。新建 `src/engine/commands/db.ts`，仿 web/excel 会话模式：指令依赖薄接口 `DbLike`，真实驱动在工厂里**懒 require**（vitest 不连真库、Electron 打包不强依赖）：

- **SQLite**：复用已装的 `better-sqlite3`（零新依赖），本地文件或 `:memory:`。
- **MySQL**：懒 `require('mysql2/promise')`；未装驱动时返回友好中文提示「请先 npm i mysql2」。
- PostgreSQL / SQL Server 本切片不接（README 已知限制登记）。

4 条新指令：
- `dbConnect`：选 sqlite/mysql，填路径或 host/port/user/password/database；
- `dbQuery`：SELECT，结果数组写入变量；
- `dbExecute`：INSERT/UPDATE/DDL，返回影响行数；
- `dbClose`：关闭连接。

资源生命周期：`RunDisposer` 接口加 `disposeDb()`，`RunManager.disposeResources()` 在每次运行结束统一关闭数据库连接（与浏览器/Excel 同生命周期），失败只记 warn。
