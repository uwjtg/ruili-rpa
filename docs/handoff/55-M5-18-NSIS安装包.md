## 1. 本阶段目标与完成情况

此前只能 `electron .` 跑开发版，没有分发包。本次接 electron-builder：

- **装依赖**：`electron-builder@^26`（devDep）。
- **package.json 加 build 配置**：
  - appId `com.ruili.rpa`，productName `锐流RPA`；
  - files 收 `out/**/*` + package.json；
  - asarUnpack `better-sqlite3`（NAPI 原生模块）；
  - `npmRebuild: false`——better-sqlite3 v13 是 NAPI 预编译，不需要 node-gyp 重编译（本机没装 VS Build Tools，默认 rebuild 会挂）；
  - win target nsis，非 oneClick、允许选安装目录、桌面+开始菜单快捷方式。
- **加 script**：`"dist": "electron-vite build && electron-builder --win nsis"`。

## 5. 遗留问题（**重要**）

1. **未配应用图标**：当前用默认 Electron 图标，需准备 `build/icon.ico`（256×256）后再打包。
2. **Python sidecar 未打进包**：当前主进程 `spawn('python', ...)` 依赖系统 PATH 里的 python + uiautomation。装机用户机器上没有 python 就跑不了桌面指令。后续要把 python embeddable zip + sidecar 脚本打到 `resources/python/`，主进程改用 `process.resourcesPath` 定位。
3. **playwright-core/Chromium**：web 指令用 channel:'chrome' 走系统 Chrome，不打 Chromium，包体积才压到 123 MB；如果要打 Chromium 会再 +150 MB。
4. **未代码签名**：exe 未签名，Windows SmartScreen 会拦；正式发版需买证书。
5. **无自动更新**：未接 electron-updater，后续要配 GitHub/自建更新源。
6. **dist-installer/ 应 gitignore**：需确认 .gitignore。
