## 5. 遗留问题（含影响与建议）

1. **本机 Git for Windows 安装异常**：`git.exe`（bin/cmd 均）报 `BUG (fork bomb)`，阶段 1 无法执行 `git init` 与基线提交。影响：暂无版本基线，代码完整落盘不阻塞阶段 2。建议：用户重装/修复 Git 后执行 `git init && git add -A && git commit` 补基线（一条命令）；或后续阶段改用 Git Bash / 其他版本管理。
2. **Electron 首次启动出现 "Downloading Electron binary"** 提示（随后正常启动）——npmmirror electron 镜像生效的迹象；离线环境可预先执行 `node node_modules/electron/install.js`。
3. **折线图档位切换**（近一周/近一月/近一年）目前仅 UI 状态切换，数据不随档位变化（阶段 1 范围外）；阶段 2+ 接真实数据时补齐。

## 6. 对下一阶段的输入要求

- **路由**：HashRouter 7 路由（`/` `/apps` `/editor` `/triggers` `/robots` `/market` `/academy`）；导航项在 `TopBar.tsx` 的 `NAV_ITEMS` 维护
- **图标**：新增图标一律加入 `iconPaths.ts`（24 viewBox 线性、描边 1.7-1.9、currentColor、禁止 emoji/图标库）；用 `<Icon name=... />` 渲染
- **设计 token**：样式不得硬编码色值；新视图先建 `styles/*.css` 在 `main.tsx` 引入
- **测试**：vitest node 环境；`*.test.ts` 与被测文件同目录；引擎核心路径（阶段 2 起）必须带单测
- **公共文件**（package.json / tsconfig 等）：改动必须在本交接文档链中显式声明
- **preload 扩展**：`window.ruili` 增加方法时同步更新 `src/renderer/src/env.d.ts`
- **阶段 2 落点**：`src/engine/core/`（AST 类型 + 解释器 + 作用域 + 断点/暂停语义）、`src/engine/commands/`（注册表 + 8 条演示指令）、`src/shared/`（`cmd-schema.ts`、`ast.ts`）；验收按《接力开发模式说明》§2
