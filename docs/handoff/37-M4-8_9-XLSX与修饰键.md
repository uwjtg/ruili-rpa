## 1. 本阶段目标与完成情况

M4-7 后剩余两个高价值小项：
- 导出只有 CSV（UTF-8 BOM），用户要 Excel 直开——加 XLSX；
- 录制器只录功能键，Ctrl+C/Ctrl+F 这类组合录不到。

**M4-8 XLSX 导出**：
1. 装 `xlsx@0.18.5`（SheetJS，Apache-2.0）；
2. webScrapeList 加参数 `xlsxPath`；runner 用 `XLSX.utils.json_to_sheet` + `writeFile` 导出；
3. spec/generate/向导透传 xlsxPath；向导第三步加 XLSX 路径输入框。

**M4-9 修饰键录制**：
1. 录制脚本 onKey 扩展：功能键白名单保留；Ctrl/Alt/Win + 单字符时序列化为
   Playwright 语法 `"Control+c"` / `"Alt+ArrowLeft"`；
2. webPressKey 指令参数 key 已是字符串，Playwright keyboard.press 原生支持组合键语法，无需改指令。

## 5. 遗留问题

1. **真浏览器端到端未冒烟**：XLSX 导出/修饰键录制均未在真实 Chrome/Edge 跑过。
2. xlsx 库只在主进程 import，renderer 未打包（体积无负担）；但写文件是同步 writeFile，大表会卡主进程。
3. 修饰键录制未处理 Shift（大写字母）——字母仍由 input 覆盖，不录。
4. iframe 支持仍未做。
